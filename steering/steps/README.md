# steps — journal

One file per working session: `YYYY-MM-DD-session-N.md`.

Expected content: the session's goals, what was done (with the commits), what
was learned, decisions handed over to `design/`, the exact state at the stop,
and the **next concrete action** — the first thing to do when picking the
work back up.

The most recent file is what settles how to resume. Unlike a design note, an
entry here is dated and **never rewritten**: it says what was true that day,
and later corrections belong in a later entry.

Parallel sessions: sort the existing names before creating yours, and never
overwrite someone else's.

Entries from before 2026-09-11 are in the private steering repository shared
by the workspace: they interleave ldpy with the other projects, and a dated
document is not split after the fact.
