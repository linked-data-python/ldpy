# 2026-11-03 — session 1 : constats de la campagne d'optimisation du corpus

Pendant le réveil de 00 h 25 (dépôt de pilotage, fiche corpus/403), les
agents Opus qui écrivent les artefacts optimisés ont trouvé trois défauts,
corrigés avec leurs tests :

- `a4a3b44` — `ex:{x}` avec `x` nul nommait `ex:None` ; il lève, comme les
  autres `None` interpolés (fiche 012).
- `6621b0a` — les graphes de `@graph as g` et de `g{ }` partageaient le
  gestionnaire de préfixes mis en cache : un `bind()` sur l'un changeait les
  autres (`tteon/seocho` écrivait `priv1:`). `@graph as g` a son propre
  gestionnaire, un graphe `g{ }` copie le partagé à son premier `bind()`.
  Même commit : une interpolation de f-IRI accepte conversion et
  spécification de format (`f<…{seq:03d}>`), qui émettaient du Python
  invalide.
- Fiche 012 : un nom préfixé à partie locale numérique n'est pas reconnu
  hors îlot (à instruire).

Les commits ne portent pas `Co-Authored-By` (consigne du harnais). Suite
verte (1 840 tests). CHANGELOG à jour, non publié.

## Prochaine action
