# 2026-09-11 — session 1 : ldpy reçoit son propre pilotage

## Objectif

Rendre le dépôt `ldpy` autoporteur : ses décisions de conception avec son
code, et des consignes que l'agent GitHub puisse lire. Départ : une demande
d'installer l'application GitHub sur `origin`.

## Ce qui a été fait

- Deux workflows GitHub (commit `2edc19f`) : `claude.yml` ne démarre que sur
  la chaîne `@claude` ; `claude-code-review.yml` relit chaque pull request en
  commentaires en ligne, sans jamais pousser. Authentification par le secret
  `CLAUDE_CODE_OAUTH_TOKEN` (abonnement), pas par clé API.
- Les 28 fiches `design/ldpy/` du dépôt de pilotage déplacées ici, à plat,
  dans `steering/design/`, index compris. Les retouches non commitées de
  Maxime ont voyagé avec : elles sont intactes dans les fiches 027 et 028.
- Deux scripts réécrits pour ce dépôt, en anglais : `steering/bin/coherence.py`
  (les sept contrôles, adaptés au rangement à plat, plus un huitième : une
  fiche qui porte encore une section « Révision du … » est refusée) et
  `steering/bin/ouvert.py` (statuts ouverts, marqueurs, prochaine action,
  `--what maxime`).
- `steering/README.md` dit les conventions ; `CLAUDE.md` à la racine donne à
  l'agent — local ou GitHub — de quoi travailler sans le CLAUDE.md de
  l'espace de travail, qui n'est dans aucun dépôt et que la CI ne verra
  jamais.

## Ce qui a été appris

- Le CLAUDE.md de l'espace de travail n'est **versionné nulle part** : la
  racine `semantic_web_micropython/` n'est pas un dépôt. Rien de ce qu'il dit
  n'atteignait GitHub.
- L'enchevêtrement redouté n'existait pas : 43 fichiers du carnet mentionnent
  ldpy, mais **17 liens seulement** pointaient vers `design/ldpy/` — 2 dans le
  carnet, 10 dans le TODO, 5 dans la fiche corpus/402 — et une seule fiche
  ldpy pointait vers un autre projet (vscode/109). Les cinq de corpus/402
  avaient échappé au premier comptage, tronqué par un `head` ; c'est
  `coherence.py` qui les a rattrapés, ce qui est exactement son office.
- `pilotage` est privé, `ldpy` public. C'est ce qui interdit de donner à la CI
  un jeton d'écriture sur le pilotage : `@claude` se déclenche sur commentaire
  d'issue, et n'importe qui peut commenter un dépôt public.

## Ce qui reste ouvert

Trois consignes de Maxime, déplacées telles quelles, non traitées :

1. fiche 027 l. 62 — la portée est mal décrite : tant qu'un graphe courant est
   déclaré par `@graph`, un `@prefix` déclaré après lie bien dessus. À
   vérifier dans le code, puis corriger la fiche en place.
2. fiche 027 l. 90 — `e{ STRLANG(?v, "en") }` et `e{ STRDT(?v, dt) }` sont-ils
   des options dans `+{ }`, `-{ }`, `m{ }` ?
3. fiche 028 l. 62 — mesurer avant de décider ; a priori pas de forme de
   lecture quadruplet tant que la communauté ne la demande pas.

Les fiches traduites en anglais : pas fait, pas décidé. La règle de langue de
`steering/README.md` les garde en français (raisonnement interne), ce qui est
défendable mais mérite un arbitrage explicite.
